#Darker Fantasy
##I am making my first own game on GODOT!

## 🎮 Play the Game

**[Play Darker Fantasy](https://walterm4lon.itch.io/darker-fantasy)**

## Quick Start

1. Open the game using the link above.
2. Press *Explore*.
3. Complete both minigames before the timer runs out.
4. Protect your five lives and reach the victory screen.

## How to Play

### Minigame 1 - Funky apples

Move through the level and collect all three apples before time runs out.

### Minigame 2 - Kill those beasts

Find and press all seven bugs before the timer reaches zero.

Failing a minigame removes one life. When all five lives are gone, the game ends.

## Features

- Two different timed minigames
- Five-life system with visible heart indicators
- Animated collectibles and interactive buttons
- Pixel-art fantasy visuals
- Original victory and death screens
- Replay and main-menu options
- Automatic progression between minigames
- Dark medieval atmosphere with some funky apples
